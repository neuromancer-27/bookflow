#BookFlow

This is a project I started to learn Backend Development Fundamentals by building a real application from ground up

The long-term goal of the project is to create a full end-to-end book tracking web application where users can:
- track books they are reading
- organize reading lists
- manage reading progress
- discover and review books

The project is currently being built incrementally while learning backend concepts step by step.

Future plans include:
- SQL database integration
- authentication
- improved UI/UX
- deployment
- feedback

This repository documents the full learning journey and evolution of the project over time.
